#🛒 ShopHub - E-Commerce-Product-Catalog
Responsive e-commerce product catalog with modular frontend architecture, client-side routing, product filtering, cart management, optimized assets, and deployment-ready structure.


## 🚀 Features

- Modular JavaScript architecture
- Client-side routing using URL hash navigation
- Product catalog
- Product search
- Category filtering
- Add to cart
- Remove from cart
- Cart total calculation
- localStorage cart persistence
- Responsive product grid
- Lazy-loaded images
- Semantic HTML structure
- Responsive mobile-first design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox
- DOM Manipulation
- localStorage
- Client-Side Routing
